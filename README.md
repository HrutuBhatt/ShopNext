# 🛒 E-Commerce Web Application

A full-stack e-commerce platform built with **Spring Boot (Java)** and **React.js**, supporting user authentication, seller dashboards, order management, analytics, and personalized product recommendations based on user behavior.

## 🚀 Features

- **User Roles**: Customer, Seller, Admin with role-based access control.
- **Authentication**: JWT-based login and signup functionality.
- **Product Management**: Sellers can list, update, and remove their products.
- **Cart & Orders**: Users can add items to cart, place orders, and track order status.
- **Order Workflow**:
  - Sellers can view new/past order items.
  - Mark order items as shipped or completed.
  - Admin can update overall order status.
- **Seller Analytics**:
  - Tracks revenue, orders, items sold, and top-selling products.
  - Dashboard for sellers with real-time stats.
- **Search History**:
  - Tracks users’ search terms for better recommendations and analytics.
- **Notifications System**:
  - Sellers get notified about pending orders.
- **Material UI**: Clean, responsive, and intuitive UI with Material-UI components.
